# Идеи

[[20 Проекты/Проекты|Проекты]]

Короткие заготовки проектов из интересных материалов. Здесь сохраняются все содержательно разные варианты; запись идеи не означает начало разработки.

Новые идеи добавляются отдельными папками с коротким описанием и ссылкой на источник. Для их обработки используется `my-life-ideas`; перед дополнением уже существующей идеи ИИ спрашивает пользователя.
