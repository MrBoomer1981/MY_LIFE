# Git и синхронизация

[[Система]]

По указанию пользователя от 2026-11-03 правильная версия базы находится на этом ПК. Репозиторий GitHub — копия локальной базы: `MrBoomer1981/MY_LIFE`, ветка `main`.

## Автоматическая отправка

Git-плагин Obsidian выполняет единый цикл «сохранить изменения коммитом → отправить в origin/main» каждые 15 минут. Раздельные таймеры коммита и push отключены. Автоматический pull, pull при запуске и pull перед отправкой отключены, чтобы чужая редакция автоматически не попадала в основную базу на ПК.

Этот цикл работает при открытом Obsidian, включённом Git-плагине, доступной сети и бодрствующем ПК. Успешный push проверяется совпадением локального `main` и `refs/heads/main` на GitHub. При отсутствии изменений новый коммит не нужен.

Не редактировать удалённый `main` с других устройств, пока этот ПК является единственным источником правильной версии. При расхождении сначала сохранить резервные копии и сравнить изменения; не выполнять автоматически pull с перезаписью локального содержимого и не использовать безусловный force-push.

## Что хранится в Git

В репозитории остаются учебные заметки, исходники, изображения, карты Canvas, основные настройки и закладки навигации. Установленные плагины с их машинными настройками, состояние окон, масштаб графа, кэши, корзина и системные файлы остаются локальными и исключены через `.gitignore`.

Случайно созданные вложенные папки `10 Учёба/.obsidian/` и `10 Учёба/10 Учёба/` убраны из базы с сохранением резервной копии вне Git. В последней находилась только пустая заметка-дубликат; содержательных учебных записей в этих папках не было.

Файл `lecture07-mib.pdf` хранится через Git LFS. На этом ПК установлен Git LFS; фильтры репозитория используют его абсолютный путь, а хук `pre-push` добавляет каталог Homebrew в PATH.
