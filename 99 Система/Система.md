# Система

[[Главная]]

Правила оформления и вспомогательные материалы базы.

Все материалы этого раздела являются служебными и исключаются из основного графа. Инструкции и скиллы хранятся здесь, отчёты и скрипты — в `Проверки/`. Для служебных файлов вне раздела требуется отдельное исключение. Постоянное правило: [[Правила ведения базы#Служебные материалы и основной граф]].

- [[Навыки ИИ для базы]] — пять режимов: понимание, архив, содержательный разбор, описание проекта и короткие идеи из материала.

Дополнено 2026-11-03: пятый режим `my-life-ideas` сохраняет все варианты проектов из интересного материала короткими заметками в [[20 Проекты/Идеи/Идеи|Идеях]].

- [[Инструкция для ИИ — дополнение конспектов]] — актуальные требования, полный порядок работы, проверка билетов и готовое поручение другому ИИ.

В панели «Закладки» Obsidian сохранены два вида: «Основной граф» для содержательных заметок и «Служебный граф» для папок `99 Система/`, `00 Входящие/` и файла `AGENTS.md`. Они используют фильтры одного хранилища; перенос файлов для переключения не требуется.
