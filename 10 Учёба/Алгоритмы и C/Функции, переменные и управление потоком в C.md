# Функции, переменные и управление потоком в C

> [!abstract] Суть
> Типы определяют допустимые значения и операции, функции объединяют вычисления, а условия и циклы выбирают порядок действий. Область видимости имени нужно отличать от времени жизни объекта.

## Переменная, тип и функция

В модели C именованная переменная обозначает объект с типом; тип определяет представление и допустимые операции. Аналогия «коробка со значением» полезна для начала, но не означает, что любой объект всегда физически расположен в памяти одинаковым способом. Указатель — объект указательного типа, способный хранить адрес объекта, а не само значение по этому адресу.

```c
#include <stdbool.h>

int int_value = 1;
const int int_value_const = 1;
bool bool_val = true;
float float_val = 1.1f;
double double_val = 1.1;
char char_val = 'a';
```

`const` запрещает менять объект через соответствующее квалифицированное имя; присваивание `int_value_const = 2` недопустимо. `char_val` можно затем присвоить `'b'`. Символ пишется в одинарных кавычках, строка — в двойных. Для контекста C11/C17 `bool`, `true`, `false` предоставляются `<stdbool.h>`; в C23 это ключевые слова.

## main и передача данных

В обычной hosted-среде пользовательское исполнение C начинается с `main` после подготовки среды. Пример из PDF разделяет ввод, вычисление и вывод:

```c
#include <stdio.h>

int main(void) {
    int start = 0;
    int n_values;
    printf("Enter the number N - number of loops: ");
    if (scanf("%d", &n_values) != 1) {
        return 1;
    }
    int sum = 0;
    for (int i = start; i <= n_values; ++i) {
        sum += i;
    }
    printf("sum = %d\n", sum);
    return 0;
}
```

`scanf` получает адрес `&n_values`, поскольку записывает результат в объект. `%d` соответствует `int`. Проверка результата чтения исключает использование неинициализированного значения при обычной ошибке формата; произвольный ввод за диапазоном `int` этим примером не обрабатывается. Цикл предполагает небольшое неотрицательное `n_values`, при котором сумма и увеличение счётчика представимы в `int`.

`return 0` означает успешное завершение. Иные коды зависят от платформы и соглашений программы; нельзя универсально назначать всем значениям 1, 2 и далее одинаковый смысл.

## Собственные функции и приведение типа

```c
int sum2nums(int num1, int num2) { return num1 + num2; }
double mul2nums(double num1, double num2) { return num1 * num2; }
```

В объявлении указываются результат, имя и типы параметров. Для целочисленного сложения результат должен быть представим; для вещественного действуют ограничения точности.

Функция из PDF, несмотря на имя, отбрасывает знаки, а не округляет к ближайшему:

```c
#include <math.h>

float round_float(double num, int dec) {
    int number_of_digits = (int)pow(10, dec);
    int num_rounded = (int)(num * number_of_digits);
    return (float)num_rounded / number_of_digits;
}
```

Пример рассчитан на небольшой неотрицательный `dec` и значения, для которых преобразования в `int` допустимы, множитель ненулевой. Для `1.2345` и `dec=2` множитель 100, преобразование `123.45` в `int` даёт 123, вещественное деление — приближённое 1.23. Для 1.239 результат также около 1.23, не 1.24. Приведение к целому отбрасывает дробную часть в сторону нуля. Без `(float)` делились бы два `int`, получалось бы целое 1.

## Область видимости и время жизни

Локальные имена доступны в своей области начиная с объявления; вложенный блок не делает свои имена доступными снаружи. В примере `scope_demo(int arg)` параметры `arg` и внешнее `int i=1` доступны в конце функции, а `j`, `k`, `w`, объявленные во вложенных блоках `if`, `for`, `else`, — нет.

Автоматические объекты обычно заканчивают жизнь при выходе из блока, но это не универсальное правило для любого объявления: статическая и динамическая длительность хранения отличаются. Если внутри `if` объявить `int *arr = malloc(...)`, при выходе исчезает локальный указатель, а выделенный блок остаётся. Потеря единственного адреса не освобождает этот блок.

## Условия и логические операции

Управляющее условие C имеет скалярный тип; ноль и нулевой указатель ложны, остальные значения истинны. Для значений из PDF:

| Условие | Результат |
|---|---|
| `0`, `false`, `0.0` | Ложь |
| `1`, `-1`, `true`, `1.1`, `'a'` | Истина |
| `1 || 0` | Истина: логическое ИЛИ |
| `1 && 0` | Ложь: логическое И |
| `1 ^ 0` | Ненулевой результат побитового XOR |

`^` не является общим логическим «числа разные»: например, результат определяется разностью битов. `||` и `&&` — логические операции с коротким замыканием. Код `'a'` равен 97 в ASCII-совместимой кодировке, а не по универсальному требованию C.

`if` выбирает первую истинную ветвь, `else` — случай, когда предыдущие условия ложны.

## switch и проваливание

```c
#include <stdio.h>

int print_color(int color) {
    switch (color) {
        case 1: printf("color 1\n"); break;
        case 2:
        case 3: printf("color 2, 3\n"); break;
        default: printf("There is no such color\n"); return -1;
    }
    return 0;
}
```

После выбора метки выполнение продолжается вниз до `break`, `return` или другого выхода. Соседние `case 2` и `case 3` объединяют обработку. В примере без `break` у `case 2` и `case 3` при `color=2` печатаются `color 2`, `color 3`, затем `NA` из `default` и выполняется `return -1`. Фигурные скобки вокруг тела `case` сами не останавливают проваливание.

## Три вида циклов

| Форма | Семантика |
|---|---|
| `for (инициализация; условие; шаг)` | Инициализация один раз, проверка перед телом, затем шаг |
| `while (условие)` | Проверка перед каждой итерацией, тело может не выполниться |
| `do { ... } while (условие);` | Первая итерация выполняется до проверки |

В демонстрации сравнения символов с `"12345"` нужен первый ввод до первой проверки: чтение неинициализированного `input_sym` недопустимо. `getchar` возвращает `int`, чтобы различать символы и `EOF`, а индекс должен оставаться в пределах строки. Корректный поясняющий вариант той же идеи:

```c
#include <stdio.h>
#include <stddef.h>

int read_matching_prefix(void) {
    const char pass[] = "12345";
    size_t i = 0;
    int input_sym;
    do {
        input_sym = getchar();
        if (input_sym == EOF || input_sym != (unsigned char)pass[i]) {
            return 0;
        }
        ++i;
    } while (i < sizeof(pass) - 1);
    return 1;
}
```

Так пример сохраняет выбор постусловия, но не читает за концом пароля и явно обрабатывает конец ввода. Это иллюстрация управления потоком, а не полноценная система аутентификации.
