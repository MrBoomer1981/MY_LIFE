# Строки, библиотеки и разделение программы на файлы

> [!abstract] Суть
> Строка C — нуль-терминированная последовательность символов в памяти. Время жизни буфера, его вместимость и право менять данные важны не меньше самих символов.

## Строковый литерал и изменяемый массив

`"Hello"` содержит `H`, `e`, `l`, `l`, `o`, `\0`: шесть байтов C. В примере `char *str_val="Hello"` указатель ссылается на литерал, изменение `str_val[0]='h'` недопустимо, хотя тип записи исторически допускается C. Практически такую ссылку следует обозначать `const char *`.

`char str_val_array[]="Hello"` создаёт отдельный массив из шести элементов, поэтому `str_val_array[0]='w'` корректно даёт `"wello"`. Запись в `[10]` выходит за границы и имеет неопределённое поведение.

## Возвращаемый адрес и время жизни

```c
#include <stddef.h>

const char *determineColor(const int color) {
    if (color == 1) return "blue";
    if (color == 2) return "green";
    return NULL;
}
```

Литералы имеют статическую длительность хранения и сохраняются после возврата. Локальный `char buf[10]="blue"` с автоматической длительностью хранения так возвращать нельзя: указатель станет недействительным после выхода из функции. Выделенный результат через `malloc` может пережить функцию; вызывающий затем отвечает за `free`.

## Числовой массив в строку

Пример источника преобразует `{1, 2, -10, 11}` в `"1, 2, -10, 11"`. `sizeof(values)/sizeof(values[0])` даёт число элементов настоящего массива, но не длину данных по указателю.

Ниже та же схема с `sprintf` в небольшой буфер и `strcat` в результат; уточнён знаковый 8-битный тип, выделено место для пустой строки и проверен размер. Используются поддерживаемые `int8_t` из `<stdint.h>`.

```c
#include <stdint.h>
#include <stddef.h>
#include <stdlib.h>
#include <stdio.h>
#include <string.h>

char *arr2str(const int8_t *arr, size_t size) {
    if ((size != 0 && arr == NULL) || size > (SIZE_MAX - 1) / 6) {
        return NULL;
    }
    char *str = malloc(size * 6 + 1);
    if (str == NULL) return NULL;
    str[0] = '\0';
    for (size_t i = 0; i < size; ++i) {
        char buf[5];
        sprintf(buf, "%d", (int)arr[i]);
        strcat(str, buf);
        if (i + 1 < size) strcat(str, ", ");
    }
    return str;
}
```

Для −128 нужны четыре печатных символа и `\0`, поэтому `buf[5]` достаточен именно для `int8_t`. В исходнике использовался обычный `char`, чья знаковость не гарантирована. На элемент достаточно четырёх символов числа и двух символов разделителя; дополнительно оставлено место для терминатора. Возвращённый буфер освобождает вызывающий. Повторное дописывание через `strcat` каждый раз ищет конец уже накопленной строки; это не пример оптимальной скорости.

## Строковые и байтовые функции

| Функция | Назначение и условие |
|---|---|
| `strlen(s)` | Длина до `\0`, без терминатора; для `"Hello"` — 5 |
| `strcpy(dest, src)` | Копирует строку вместе с `\0`; места должно хватать |
| `strcat(dest, src)` | Дописывает в конец существующей строки; нужна достаточная вместимость |
| `strcmp(a,b)` | Сравнивает содержимое, 0 означает равенство |
| `strchr(s,'a')` | Ищет символ, возвращает адрес либо `NULL` |
| `strstr(s,"abc")` | Ищет подстроку |
| `strtok(s,",")` | Выделяет токены и меняет исходный буфер |
| `strdup(s)` | Создаёт выделенную копию, требующую `free`; POSIX и C23, не обязательная функция C11/C17 |
| `sprintf(buf,"%d",42)` | Форматирует в строку без контроля вместимости |
| `snprintf(buf,sizeof buf,"%d",42)` | Ограничивает объём записи; по возвращаемому значению определяется усечение |
| `sscanf("42","%d",&x)` | Разбирает данные из строки, число успешных преобразований нужно проверять |
| `memset(buf,0,sizeof buf)` | Заполняет байты |
| `memcpy(dest,src,n)` | Копирует `n` байтов, области не должны перекрываться |

Строковые функции находятся в `<string.h>`, форматирование и разбор — в `<stdio.h>`. `a==b` для указателей на строки проверяет совпадение адресов, а не текста; для содержимого используют `strcmp(a,b)==0`.

## Заголовки и реализация

`<stdio.h>` содержит объявления ввода-вывода, `<stdlib.h>` — выделения памяти и преобразований, включая `atoi` и целочисленный `abs`; `<string.h>` — строк и байтов; `<math.h>` — `pow`, `fabs` и другие математические функции. Указание `abs` в `<math.h>` в исходнике исправлено. `<stdbool.h>` используется для C11/C17. Включение `<...>` и `"..."` различается поиском заголовка: кавычки обычно начинают с расположения текущего файла, точные пути задаёт реализация и параметры сборки.

`.h` описывает интерфейс: объявления функций и типы; `.c` содержит реализации. Заголовок не ограничен исключительно объявлениями, но определение общего внешнего объекта в заголовке может вызвать множественные определения при сборке нескольких файлов.

Пример цвета из PDF с исправленным размещением общей константы:

```c
/* color.h */
#ifndef COLOR_H
#define COLOR_H

struct Color {
    unsigned char red;
    unsigned char green;
    unsigned char blue;
};
extern const struct Color COLOR_BLACK;
struct Color *removeRedChannel(const struct Color *color);

#endif
```

```c
/* color.c */
#include "color.h"
#include <stdlib.h>

const struct Color COLOR_BLACK = {0, 0, 0};

struct Color *removeRedChannel(const struct Color *color) {
    if (color == NULL) return NULL;
    struct Color *color_copy = malloc(sizeof *color_copy);
    if (color_copy != NULL) {
        *color_copy = *color;
        color_copy->red = 0;
    }
    return color_copy;
}
```

При восьмибитном `unsigned char` каждый канал имеет диапазон 0–255. Присваивание структуры копирует поля; `p->red` — обращение через указатель, `COLOR_BLACK.red` — через объект. Новую структуру освобождает вызывающий. В исходной версии константа определялась непосредственно в заголовке; здесь определение оставлено только в `.c`.
