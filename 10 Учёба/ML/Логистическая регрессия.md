# Логистическая регрессия

[[10 Учёба/ML/ML|ML]]

Базовый классификатор. Для текста удобно сочетать его с TF-IDF. `make_pipeline` обучает преобразование признаков и классификатор, а при прогнозе применяет ту же последовательность к новым строкам.

Зависимости для примера — `pip install scikit-learn`.

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline

texts = ["плохой товар", "ужасный товар", "отличный товар", "хороший товар"]
labels = [0, 0, 1, 1]
model = make_pipeline(TfidfVectorizer(), LogisticRegression())
model.fit(texts, labels)
print(model.predict(["отличный товар"]))
```
