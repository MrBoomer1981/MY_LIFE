# Линейная регрессия

[[10 Учёба/ML/ML|ML]]

Предсказывает числовую величину по признакам. `LinearRegression.fit` подбирает коэффициенты методом наименьших квадратов, а `predict` возвращает числовой прогноз.

Зависимости для примера — `pip install scikit-learn`.

```python
from sklearn.linear_model import LinearRegression

X = [[1], [2], [3]]
y = [3, 5, 7]
model = LinearRegression().fit(X, y)
print(model.predict([[4]]))  # [9.]
```
