# Python — декораторы и композиция

> [!abstract] Суть
> Декоратор преобразует объект функции при её определении. Обёртка, которую он может вернуть, выполняется позднее — при вызове.

## Преобразование функции

Запись `@decorate` над определением `f` соответствует последующему присваиванию `f = decorate(f)`. Распространённый вариант декоратора возвращает новую функцию-обёртку, которая делает дополнительные действия и вызывает исходную функцию. Но декоратор в общем случае не обязан возвращать именно обёртку.

Обёртка часто является замыканием: она сохраняет исходную функцию через внешнюю связь. Благодаря этому новая функция может вызывать прежнюю, даже когда имя `f` уже указывает на обёртку.

## Три момента выполнения

Декоратор с параметрами сначала получает настройки и возвращает декоратор. Затем декоратор получает функцию и создаёт обёртку. Наконец, обёртка выполняется при каждом вызове.

Постоянная настройка может сохраняться при создании, а проверка изменяемого состояния должна происходить в момент использования. Если вычислить разрешение доступа единожды при создании обёртки, дальнейшие изменения состояния не будут автоматически учтены.

## Передача поведения

`*args` и `**kwargs` позволяют обёртке собрать аргументы и затем передать их исходной функции. Без распаковки передаются сами контейнеры как отдельные аргументы, что меняет смысл вызова.

Если обёртка не возвращает результат исходной функции, вызывающий получает `None`. Если исключение не перехвачено, оно проходит наружу. Значит, сохранение поведения включает аргументы, результат и исключения, а не только сам факт вызова.

`functools.wraps` помогает сохранить имя, документацию и связь `__wrapped__` с исходной функцией. Это важно для introspection — программного изучения объекта. Сохранение метаданных не означает, что обёртка автоматически повторяет всю семантику исходного объекта.

## Порядок композиции

Два декоратора `@outer` и `@inner` соответствуют `f = outer(inner(f))`. Ближайший к определению применяется первым; при вызове внешняя обёртка обычно начинает работу первой.

Если внешняя обёртка ведёт журнал, она может увидеть отказ внутренней проверки доступа. Если проверка доступа находится снаружи и прекращает выполнение, внутренняя обёртка журнала не вызывается. Перестановка декораторов меняет поведение, потому что композиция функций в общем случае некоммутативна.
