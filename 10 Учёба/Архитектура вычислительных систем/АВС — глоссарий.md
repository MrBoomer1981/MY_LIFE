[[Архитектура вычислительных систем]]

# АВС — глоссарий

> [!abstract] Суть
> Термины и сокращения исходного конспекта; подробное объяснение дано в тематических заметках.

| Термин | Расшифровка | Значение |
|---|---|---|
| AHCI | Advanced Host Controller Interface | Программный интерфейс управления SATA-контроллером |
| APIC | Advanced Programmable Interrupt Controller | Контроллер прерываний, логические CPU имеют APIC ID |
| CAS Latency (CL) | Column Address Strobe Latency | Задержка выдачи данных после команды чтения |
| CIA | Confidentiality, Integrity, Availability | Конфиденциальность, целостность, доступность |
| CISC | Complex Instruction Set Computer | Подход с богатым набором команд, пример — x86 |
| CUDA | Compute Unified Device Architecture | Платформа и модель программирования GPU NVIDIA |
| DAS | Direct Attached Storage | Прямо подключённое хранилище |
| DDR | Double Data Rate | Передача данных дважды за такт |
| DIMM / SO-DIMM | Dual In-line Memory Module / Small Outline DIMM | Полноразмерный и компактный модули памяти |
| ECC | Error-Correcting Code | Код коррекции ошибок памяти |
| E1.S / E1.L | Форматы семейства EDSFF | Серверные форм-факторы накопителей |
| ELK | Elasticsearch, Logstash, Kibana | Стек сбора, поиска и визуализации логов |
| FC | Fibre Channel | Специализированный транспорт хранения |
| FCH | Fusion Controller Hub | Название чипсета в примерах AMD |
| GPU | Graphics Processing Unit | Графический процессор, также для параллельных вычислений |
| HBA | Host Bus Adapter | Адаптер подключения устройств хранения или сети SAN |
| HDD | Hard Disk Drive | Магнитный жёсткий диск |
| Hot Plug | Горячее подключение | Подключение/отключение без выключения при поддержке всей системой |
| IaaS / PaaS / SaaS | Infrastructure / Platform / Software as a Service | Облачные модели разделения ответственности |
| IB | InfiniBand | Высокоскоростная сеть для кластеров и хранения |
| IOPS | Input/Output Operations Per Second | Операции ввода-вывода в секунду |
| ISA | Instruction Set Architecture | Набор команд и архитектурные правила процессора |
| iSCSI | Internet SCSI | Передача SCSI по TCP/IP |
| ISL | InterSwitch Link | Связь между коммутаторами фабрики |
| JBOD | Just a Bunch Of Disks | Набор отдельных дисков; также полка или последовательное объединение без избыточности |
| LGA / PGA | Land / Pin Grid Array | Контактные площадки CPU с контактами в сокете / выводы на CPU |
| LVM | Logical Volume Manager | Менеджер логических томов Linux |
| LV / VG / PV | Logical Volume / Volume Group / Physical Volume | Логический том / группа томов / физический том |
| LE / PE | Logical / Physical Extent | Единицы распределения логического / физического пространства |
| LTO | Linear Tape-Open | Стандарт ленточного хранения |
| M.2 | Обозначение форм-фактора | Компактные модули, в том числе накопители; не синоним NVMe |
| Middleware | Промежуточное ПО | Связь компонентов и доступ к ресурсам |
| MISC | Minimal Instruction Set Computer | Подход с минимальным набором инструкций |
| MOM | Message-Oriented Middleware | Промежуточное ПО обмена сообщениями |
| MTBF | Mean Time Between Failures | Статистическая средняя наработка между отказами |
| NAND, SLC/MLC/TLC/QLC | Флеш-память; Single-/Multi-/Triple-/Quad-Level Cell | В таблице источника — 1/2/3/4 бита в ячейке |
| NAS | Network Attached Storage | Файловый доступ по сети |
| NFS / SMB | Network File System / Server Message Block | Сетевые файловые протоколы |
| NIST | National Institute of Standards and Technology | Организация, с эталонной облачной архитектурой которой связана модель курса |
| NVMe | Non-Volatile Memory Express | Спецификации доступа к энергонезависимой памяти |
| P/E | Program/Erase | Цикл программирования и стирания NAND |
| PCH | Platform Controller Hub | Название чипсета в примерах Intel |
| PCIe | PCI Express | Высокоскоростное подключение GPU, SSD и других устройств |
| RAID | Redundant Array of Independent Disks | Массив с выбранной схемой чередования и/или избыточности |
| RDIMM / UDIMM | Registered / Unbuffered DIMM | Регистрируемые / небуферизованные модули памяти |
| RISC | Reduced Instruction Set Computer | Подход с регулярными, сравнительно простыми операциями |
| ROI | Return on Investment | Отдача от вложений |
| Runtime | Среда выполнения | Исполнение программы, например Node.js или JRE |
| SAN | Storage Area Network | Сеть хранения с блочным доступом |
| SAS | Serial Attached SCSI | Последовательное подключение с командами SCSI |
| SATA | Serial ATA | Последовательное подключение устройств ATA |
| SCSI | Small Computer System Interface | Семейство стандартов команд и взаимодействия с устройствами |
| SDN | Software Defined Networking | Программно определяемая сеть |
| SDS | Software Defined Storage | Программно определяемое хранение |
| SoC | System on a Chip | Интеграция вычислительных и периферийных блоков на кристалле |
| SSD | Solid-State Drive | Твердотельный накопитель |
| Target / Initiator | Целевое устройство / инициатор | Исполнитель запросов / источник запросов |
| TCO | Total Cost of Ownership | Полная стоимость владения |
| TDP | Thermal Design Power | Расчётная тепловая характеристика для проектирования охлаждения |
| Tiering | Ярусное хранение | Размещение горячих и холодных данных на разных классах носителей |
| TRIM | Команда освобождения диапазонов | Уведомление SSD о более не нужных логических блоках |
| U | Rack Unit | Единица высоты оборудования в стойке, 44,45 мм |
| VLIW | Very Long Instruction Word | Длинная команда с несколькими планируемыми компилятором операциями |
| VRAM | Video RAM | Память GPU |
| XOR | Exclusive OR | Исключающее ИЛИ, используемое для чётности |
| Макрокоманда / микрооперация | Инструкция ISA / µop | Внешняя команда / внутреннее элементарное действие CPU |
| Северный / южный мост | Northbridge / Southbridge | Исторические узлы связи с быстрой памятью и периферией |
| Фабрика | Fabric | Сеть коммутаторов SAN |
| Экспандер | SAS Expander | Соединение множества SAS-устройств с инициатором |
