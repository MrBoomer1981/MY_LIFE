# Сохранение отношений и полиморфизмы

Сохранение отношения означает, что функция, применённая покоординатно к допустимым наборам, снова даёт допустимый набор. Так пять разных свойств булевых функций записываются одним способом.

## Арность функции и отношения

Пусть $B=\{0,1\}$, $R\subseteq B^m$ — $m$-местное отношение, $f:B^n\to B$ — $n$-местная функция. Эти два числа независимы: $n$ — сколько аргументов принимает функция, $m$ — сколько координат содержит элемент отношения. Определение отношения произвольной арности разобрано в [[Бинарные отношения, эквивалентность и порядок#Отношения произвольной арности]].

Возьмём **любые** $n$ элементов отношения $a^{(1)},\ldots,a^{(n)}\in R$. Функция сохраняет $R$, если

$$\bigl(f(a_1^{(1)},\ldots,a_1^{(n)}),\ldots,
f(a_m^{(1)},\ldots,a_m^{(n)})\bigr)\in R.$$

Иначе говоря, элементы $R$ записываются **столбцами** матрицы из $m$ строк и $n$ столбцов; к каждой строке применяется $f$. Столбец из полученных значений должен лежать в $R$:

$$\begin{pmatrix}
a_1^{(1)}&\cdots&a_1^{(n)}\\
\vdots&&\vdots\\
a_m^{(1)}&\cdots&a_m^{(n)}
\end{pmatrix}
\quad\xrightarrow{\ f\text{ по строкам}\ }\quad
\begin{pmatrix}
f(a_1^{(1)},\ldots,a_1^{(n)})\\
\vdots\\
f(a_m^{(1)},\ldots,a_m^{(n)})
\end{pmatrix}\in R.$$

Все сохраняющие $R$ булевы функции всех положительных арностей образуют $\operatorname{Pol}(R)$ — **класс полиморфизмов отношения**. Запись IMG_4127–IMG_4128 здесь раскрыта с квантором «для любых»: проверки одной удачной матрицы недостаточно.

## Сохранение порядка на примере большинства

Для $R_{\le}=\{(0,0),(0,1),(1,1)\}$ столбцы — сравнимые пары битов. Если строки матрицы обозначены $\alpha,\beta$, то требование к столбцам означает $\alpha_i\le\beta_i$ для всех $i$. Выход принадлежит $R_{\le}$ ровно при $f(\alpha)\le f(\beta)$. Поэтому

$$\operatorname{Pol}(R_{\le})=M.$$

В таблице IMG_4127 функция имеет вектор $q=00010111$: это большинство трёх аргументов, $q(x,y,z)=xy\lor xz\lor yz$. Единицы стоят ровно на наборах с двумя или тремя единицами. Матрицы из рукописи читаются так:

$$\begin{pmatrix}0&0&0\\1&1&1\end{pmatrix}
\mapsto\binom{q(000)}{q(111)}=\binom01\in R_{\le},$$
$$\begin{pmatrix}0&1&0\\0&1&1\end{pmatrix}
\mapsto\binom{q(010)}{q(011)}=\binom01\in R_{\le}.$$

**Дополнительное обоснование для всех матриц:** если $\alpha\le\beta$, число единиц при переходе к $\beta$ не уменьшается. Если $q(\alpha)=1$, в $\alpha$ хотя бы две единицы; они сохраняются в $\beta$, значит $q(\beta)=1$. При $q(\alpha)=0$ неравенство $q(\alpha)\le q(\beta)$ выполняется при любом выходе. Следовательно, большинство действительно принадлежит $\operatorname{Pol}(R_{\le})$, а не только проходит два частных сравнения.

Покоординатный порядок изображён на [[Замкнутые классы булевых функций и полнота#Покоординатный порядок на булевом кубе|булевом кубе]]. Наборы $100$ и $011$ несравнимы: первая координата запрещает $100\le011$, вторая — $011\le100$.

## Пять классов как классы полиморфизмов

В IMG_4128 приведены следующие отношения. Здесь $L$ содержит и свободный член, то есть аффинные функции над $\mathbb F_2$:

| Класс функций | Сохраняемое отношение | Арность отношения |
| --- | --- | --- |
| $T_0$ | $R_0=\{(0)\}$ | 1 |
| $T_1$ | $R_1=\{(1)\}$ | 1 |
| $M$ | $R_{\le}=\{(0,0),(0,1),(1,1)\}$ | 2 |
| $S$ | $R_{\ne}=\{(0,1),(1,0)\}$ | 2 |
| $L$ | $R_{\oplus}=\{(a,b,c,d)\in B^4:a\oplus b\oplus c\oplus d=0\}$ | 4 |

Каждая строка означает равенство класса с $\operatorname{Pol}(R)$. Соответствия $M,S,L$ дополнительно сверены с первичным источником: [E. Jeřábek, On the complexity of the clone membership problem, определения основных булевых клонов](https://users.math.cas.cz/~jerabek/papers/clonememb.pdf). В нём аффинный класс обозначен $A$, самодвойственный — $D$; здесь сохранены обозначения курса $L,S$.

### Сохранение констант и самодвойственность

Для $R_0$ все выбранные столбцы состоят из единственного 0, так что выход — $f(0,\ldots,0)$. Он лежит в $\{0\}$ ровно при $f\in T_0$. Для $R_1$ то же определение непосредственно даёт $f(1,\ldots,1)=1$.

Для $R_{\ne}$ каждый столбец — $(0,1)$ или $(1,0)$. Следовательно, две строки матрицы имеют вид $\alpha,\overline\alpha$. Выход остаётся неравной парой ровно тогда, когда

$$f(\overline\alpha)=\overline{f(\alpha)}\qquad\text{для всех }\alpha,$$

то есть $f\in S$. Так условие на пары противоположных строк таблицы становится сохранением одного бинарного отношения.

### Почему четырёхместная чётность задаёт линейный класс

**Дополнительное доказательство соответствия из рукописи.** Пусть $f(x)=a_0\oplus\bigoplus_i a_ix_i$. Если четыре строки входной матрицы — $u,v,w,t$, условие на каждый столбец означает $u\oplus v\oplus w\oplus t=0$ покоординатно. Тогда

$$f(u)\oplus f(v)\oplus f(w)\oplus f(t)
=(a_0\oplus a_0\oplus a_0\oplus a_0)
\oplus\bigoplus_i a_i(u_i\oplus v_i\oplus w_i\oplus t_i)=0.$$

Итак, $f$ сохраняет $R_{\oplus}$. Четыре повторения свободного члена уничтожаются, поэтому допускается и $a_0=1$.

Обратно, пусть $f$ сохраняет $R_{\oplus}$. Возьмём любые $u,v\in B^n$ и строки $u,v,0,u\oplus v$: их столбцы имеют чётную сумму. Получаем

$$f(u)\oplus f(v)\oplus f(0)\oplus f(u\oplus v)=0.$$

Положим $g(x)=f(x)\oplus f(0)$. Тогда $g(0)=0$ и $g(u\oplus v)=g(u)\oplus g(v)$. Каждый набор раскладывается как $x=\bigoplus_{i:x_i=1}e_i$, где $e_i$ — единичный набор. Повторяя аддитивность, выводим

$$g(x)=\bigoplus_i g(e_i)x_i,\qquad
f(x)=f(0)\oplus\bigoplus_i g(e_i)x_i\in L.$$

Оба включения доказаны. Четырёхместность существенна для свободного члена: нельзя без оговорок заменять здесь отношение на трёхместное $a\oplus b\oplus c=0$.

## Малые таблицы и проверка сохранения

В нижней таблице IMG_4128 три столбца значений при порядке $00,01,10,11$ равны $0101$, $0010$, $0100$. Заголовки операций написаны неясно; по самим значениям функции определяются однозначно:

| $xy$ | Проекция $y$ | $x\land\neg y$ | $\neg x\land y$ |
| --- | --- | --- | --- |
| 00 | 0 | 0 | 0 |
| 01 | 1 | 0 | 1 |
| 10 | 0 | 1 | 0 |
| 11 | 1 | 0 | 0 |

**Дополнительное пояснение к чтению таблицы:** проекция всегда сохраняет любое отношение, поскольку возвращает один из выбранных входных столбцов. Обе разности сохраняют 0. Но они не сохраняют $R_{\ne}$: для двух столбцов $(0,1),(0,1)\in R_{\ne}$ строки равны $00$ и $11$, а обе функции дают выход $(0,0)\notin R_{\ne}$. Одна неудачная матрица опровергает сохранение; одна удачная его не доказывает.

## Замкнутость класса полиморфизмов

**Дополнительное обоснование связи с замыканием.** Если $f,g_1,\ldots,g_k$ сохраняют $R$, то $h(x)=f(g_1(x),\ldots,g_k(x))$ тоже сохраняет $R$. Действительно, возьмём любые входные столбцы из $R$. Применение каждой $g_j$ по строкам даёт новый столбец из $R$. Таких столбцов $k$; применяя к ним по строкам $f$, снова получаем элемент $R$, и это именно результат применения $h$. Проекции сохраняют $R$, поскольку выбирают один исходный столбец. Значит, $\operatorname{Pol}(R)$ замкнут относительно суперпозиции и содержит все проекции.

Это единый механизм [[Замкнутые классы булевых функций и полнота#Доказательства замкнутости|замкнутости пяти классов Поста]]. Константы здесь не разрешаются автоматически: постоянная функция сохраняет лишь те отношения, которые содержат соответствующий постоянный кортеж.
