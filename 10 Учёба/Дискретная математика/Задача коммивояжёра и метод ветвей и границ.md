# Задача коммивояжёра и метод ветвей и границ

В задаче коммивояжёра ищут гамильтонов цикл наименьшего веса. Нижние оценки позволяют исключать целые семейства циклов, не перебирая их по одному.

## Постановка

Для матрицы стоимостей $C=(c_{ij})$ требуется посетить каждую вершину один раз и вернуться в начало. В ориентированном случае $c_{ij}$ и $c_{ji}$ могут различаться. Запрещённые переходы, включая диагональ, обозначаются $+\infty$. Вес цикла — сумма выбранных дуг. Каждому допустимому циклу отвечает ровно один выбранный элемент в каждой строке и каждом столбце; обратное неверно, потому что выбор может образовать несколько непересекающихся подциклов.

## Приведение матрицы и нижняя оценка

Из каждой строки вычитаем её минимальный конечный элемент, затем из каждого столбца приведённой матрицы — его минимум. Сумма вычтенных минимумов $L$ — нижняя оценка стоимости цикла: каждый цикл использует по одному элементу каждой строки и столбца, поэтому его исходный вес равен $L$ плюс вес в приведённой неотрицательной матрице.

Наличие строки или столбца без конечных допустимых переходов означает невозможность соответствующей ветви. В качестве верхней оценки $U$ берётся стоимость любого уже построенного допустимого цикла.

## Разобранный пример практики

$$C=\begin{pmatrix}
\infty&1&3&1&2\\
2&\infty&5&4&6\\
2&4&\infty&6&1\\
3&1&5&\infty&4\\
3&2&4&1&\infty
\end{pmatrix}.$$

Строчные минимумы $(1,2,1,1,1)$ дают 6. После их вычитания минимумы столбцов равны $(0,0,2,0,0)$, добавляем ещё 2:

$$L=8,\quad C'=\begin{pmatrix}
\infty&0&0&0&1\\
0&\infty&1&2&4\\
1&3&\infty&5&0\\
2&0&2&\infty&3\\
2&1&1&0&\infty
\end{pmatrix}.$$

Цикл $1\to2\to3\to4\to5\to1$ имеет стоимость $1+5+6+4+3=19$, поэтому $8\le\mathrm{OPT}\le19$.

## Ветвление по нулевой дуге

Для нуля $c'_{ij}=0$ рассматриваем две ветви: включить дугу $i\to j$ или запретить её. Если запретить, из строки $i$ придётся выйти другой дугой, а в столбец $j$ войти другой. Поэтому дополнительная нижняя оценка

$$\theta_{ij}=\min_{k\ne j}c'_{ik}+\min_{m\ne i}c'_{mj}.$$

Это штраф за исключение нуля. В качестве эвристики выбора ветвления берут нуль с наибольшим штрафом. **Уточнение:** большой штраф не разрешает навсегда отбросить другую ветвь без сравнения её нижней оценки с лучшим найденным допустимым циклом.

В начальной приведённой матрице

$$\theta_{12}=0,\quad\theta_{13}=1,\quad\theta_{14}=0,\quad\theta_{21}=2,\quad\theta_{35}=2,\quad\theta_{42}=2,\quad\theta_{54}=1.$$

**Исправление источника:** для $\theta_{14}$ в одной строке записано $0+2=2$, но в столбце 4 после исключения первой строки остаётся нуль строки 5, поэтому правильный штраф 0. Выбор дуги $2\to1$ остаётся допустимым среди максимальных штрафов.

## Включение дуг и запрет подциклов

При включении $i\to j$ удаляем строку $i$ (её выход выбран) и столбец $j$ (её вход выбран). Для цепочки уже включённых дуг $a\to\cdots\to b$ запрещаем $b\to a$, пока цепочка не охватила все вершины. Запрет одной лишь обратной дуги достаточен только для цепочки длины 1; в общем нужно следить за её концами.

Включаем $2\to1$: удаляем строку 2, столбец 1, запрещаем $1\to2$. Дополнительных вычитаний нет, нижняя оценка остаётся 8. В оставшейся матрице штрафы

$$\theta_{13}=1,\quad\theta_{14}=0,\quad\theta_{35}=4,\quad\theta_{42}=3,\quad\theta_{54}=1.$$

Включаем $3\to5$, запрещаем $5\to3$, удаляем строку 3 и столбец 5. Нижняя оценка всё ещё 8; далее $\theta_{42}=3$ — наибольший штраф. Включаем $4\to2$, получаем цепочку $4\to2\to1$ и запрещаем $1\to4$. Оставшиеся допустимые нулевые переходы вынуждают $1\to3$ и $5\to4$.

Полученный цикл

$$2\to1\to3\to5\to4\to2$$

имеет исходную стоимость $2+3+1+1+1=8$. Она совпала с нижней оценкой всего исходного семейства, поэтому цикл глобально оптимален, а остальные ветви можно отбросить. Именно совпадение оценок завершает доказательство оптимальности; одного рисунка дерева ветвления было бы недостаточно.
