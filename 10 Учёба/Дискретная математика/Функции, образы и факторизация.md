# Функции, образы и факторизация

Функция сопоставляет каждому аргументу ровно одно значение. Факторизация отделяет объединение равнозначных аргументов от последующего взаимно однозначного соответствия с образом.

## Функция как отношение

Функциональное отношение $f\subseteq A\times B$ удовлетворяет

$$(a,b)\in f\land(a,c)\in f\Rightarrow b=c.$$

Чтобы это была всюду определённая функция $f:A\to B$, нужно также существование значения для каждого $a\in A$. Одна лишь записанная в лекции однозначность допускает частичную функцию.

Область определения $D_f=\{a\in A\mid\exists b:(a,b)\in f\}$. Для всюду определённой функции $D_f=A$. Образ $f(A)=\{f(a)\mid a\in A\}$ может быть собственным подмножеством $B$; множество $B$ задаётся при определении функции и не обязано совпадать с образом.

Для $A_1\subseteq A$, $B_1\subseteq B$:

$$f(A_1)=\{b\in B\mid\exists a\in A_1:f(a)=b\},\qquad f^{-1}(B_1)=\{a\in A\mid f(a)\in B_1\}.$$

Прообраз множества определён и без существования обратной функции.

## Инъекция, сюръекция, биекция

Инъективность: $f(a_1)=f(a_2)\Rightarrow a_1=a_2$. Сюръективность: $\forall b\in B\ \exists a\in A:f(a)=b$. Биекция обладает обоими свойствами. При изменении множества значений с $B$ на $f(A)$ функция становится сюръективной, хотя её значения на аргументах не меняются.

## Факторизация по одинаковым значениям

Положим $a\sim b\iff f(a)=f(b)$. Равенство значений рефлексивно, симметрично и транзитивно, поэтому это эквивалентность. Определим

$$q:A\to A/{\sim},\quad q(a)=[a],$$
$$h:A/{\sim}\to f(A),\quad h([a])=f(a),$$
$$j:f(A)\hookrightarrow B,\quad j(b)=b.$$

$h$ корректно определена: представители одного класса имеют одно значение. Она инъективна, поскольку одинаковые значения означают одинаковые классы; сюръективна по определению $f(A)$. Поэтому

$$f=j\circ h\circ q$$

в обычном соглашении композиции функций «справа налево». В практике написано $q\circ h\circ j$ в принятом там порядке последовательного прохождения отношений; это тот же путь аргумента, а не другая факторизация.

### Пример из практики

$A=\{a,b,c,d,e\}$, $B=\{1,2,3,4,5,6\}$ и

$$f(a)=f(c)=2,\quad f(b)=f(e)=5,\quad f(d)=4.$$

Тогда

$$A/{\sim}=\{\{a,c\},\{b,e\},\{d\}\},\qquad f(A)=\{2,4,5\}.$$

$q$ отправляет $a,c$ в один класс, $b,e$ — во второй, $d$ — в третий. $h$ отправляет эти три класса соответственно в $2,5,4$, после чего $j$ рассматривает те же числа как элементы $B$. Три класса отражают три разных значения исходной функции.
