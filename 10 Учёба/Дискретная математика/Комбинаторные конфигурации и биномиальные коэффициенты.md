# Комбинаторные конфигурации и биномиальные коэффициенты

При подсчёте важно различать порядок выбранных объектов, возможность повторений и различимость предметов. Эти три решения определяют формулу.

## Размещения, перестановки и сочетания

Пусть есть $m$ возможных значений и $n$ позиций. В лекции используются $U(m,n),A(m,n),P(n),C(m,n),V(m,n)$; в практике — $\overline A_m^n,A_m^n,P_n,C_m^n,\overline C_m^n$.

| Конфигурация | Число |
| --- | --- |
| Упорядоченный выбор с повторениями | $U(m,n)=m^n$ |
| Упорядоченный выбор без повторений | $A(m,n)=m(m-1)\cdots(m-n+1)=m!/(m-n)!$ |
| Перестановка $n$ различных объектов | $P(n)=n!$ |
| Неупорядоченный выбор без повторений | $C(m,n)=\binom mn=m!/(n!(m-n)!)$ |
| Неупорядоченный выбор с повторениями | $V(m,n)=\binom{m+n-1}{n}$ при $m\ge1$ |

При $n>m$ выбор без повторений невозможен: $A(m,n)=C(m,n)=0$. Пустой выбор единственен: $A(m,0)=C(m,0)=1$, $0!=1$.

**Доказательства из лекции.** Для $U$ каждый из $n$ различимых предметов независимо направляется в один из $m$ ящиков. Для $A$ после первого выбора остаётся $m-1$ вариантов, затем $m-2$ и т. д. Перестановки — случай $m=n$. Каждый неупорядоченный $n$-элементный выбор допускает ровно $n!$ порядков, поэтому $C=A/n!$.

**Дополнительное доказательство формулы с повторениями** (в источнике оставлено для самостоятельного обоснования). Выбор задаётся числами $x_1+\cdots+x_m=n$, $x_i\ge0$. Запишем $n$ одинаковых звёзд и $m-1$ разделителей: числа звёзд между соседними разделителями — $x_i$. Выбрать позиции звёзд среди $m+n-1$ мест можно $\binom{m+n-1}{n}$ способами. Это обоснование формулы, а не новое упражнение.

Если среди $N=k_1+\cdots+k_m$ объектов одинаковые объекты каждого из $m$ типов не различаются, число перестановок

$$P(k_1,\ldots,k_m)=\frac{N!}{k_1!\cdots k_m!}.$$

**Промежуточное обоснование:** пометим временно все объекты. Получим $N!$ перестановок; каждая непомеченная возникает $k_1!\cdots k_m!$ раз за счёт перестановок внутри типов.

## Примеры конфигураций из лекции

Два броска правильной кости — упорядоченная пара из шести значений: $6^2=36$ исходов; сумма $12$ получается только при $(6,6)$, вероятность $1/36$. Три призовых места среди $n\ge3$ участников задают $n(n-1)(n-2)$ исходов при отсутствии ничьих. Начальная рука из семи костей домино выбирается из 28 без учёта порядка: $\binom{28}{7}=1\,184\,040$.

В слове «огород» шесть букв, из них три «о»: всего $6!/3!=120$ различных перестановок. Если все три «о» стоят вместе, считаем блок «ооо» одним объектом вместе с «г», «р», «д»: $4!=24$. Поэтому перестановок, где три «о» не образуют один общий блок, $120-24=96$. Это условие допускает две соседние «о»; оно не означает попарного разделения всех «о».

В карточном примере практики разобраны три непересекающихся случая пересечения требований «ровно один король, ровно две дамы, ровно одна пиковая карта» в колоде 36 карт. Если пиковая карта — король: $1\cdot\binom32\binom{21}2=630$. Если это дама: $3\cdot1\cdot3\binom{21}2=1890$. Если это карта иного достоинства: $3\binom32\cdot7\cdot21=1323$. Здесь 21 — непиковые карты, не являющиеся королями или дамами, 7 — пиковые карты остальных достоинств. Всего $630+1890+1323=3843$.

## Биномиальные коэффициенты

$$\binom n0=\binom nn=1,\qquad\binom nk=\binom n{n-k},$$
$$\binom nk=\binom{n-1}k+\binom{n-1}{k-1},\qquad\sum_{k=0}^n\binom nk=2^n.$$

Симметрия следует из факториальной формулы или перехода к дополнению выбранного подмножества. Для равенства Паскаля отделяем $k$-элементные подмножества, содержащие фиксированный элемент, от остальных. Алгебраическая проверка из практики:

$$\frac{(n-1)!}{k!(n-1-k)!}+\frac{(n-1)!}{(k-1)!(n-k)!}=\frac{(n-1)!((n-k)+k)}{k!(n-k)!}=\frac{n!}{k!(n-k)!}.$$

Сумма считает все подмножества: каждый из $n$ элементов можно включить или не включить.

## Бином Ньютона

$$(a+b)^n=\sum_{k=0}^n\binom nk a^k b^{n-k}.$$

При раскрытии $n$ скобок член $a^kb^{n-k}$ возникает, когда в $k$ выбранных скобках берём $a$, а в остальных $b$. Число таких выборов — $\binom nk$, чем и доказана формула.

Разобранный в практике наибольший член $(\sqrt3+1)^{100}$:

$$T_k=\binom{100}k(\sqrt3)^k.$$

Отношения соседей дают

$$T_k>T_{k-1}\iff k<\frac{101\sqrt3}{1+\sqrt3},\qquad T_k>T_{k+1}\iff k>\frac{100\sqrt3-1}{1+\sqrt3}.$$

Границы приблизительно $64.03$ и $63.03$, поэтому $k=64$ и

$$T_{64}=\frac{100!}{64!36!}\,3^{32}.$$

## Формула Стирлинга

В лекции приведена оценка без доказательства, при $n\ge1$:

$$\sqrt{2\pi n}\left(\frac ne\right)^n<n!<\sqrt{2\pi n}\left(\frac ne\right)^n e^{1/(12n)}.$$

Отсюда $n!\sim\sqrt{2\pi n}(n/e)^n$. Следует сохранять множитель $n^n$: запись $\sqrt{2\pi n}\,e^{-n}$ без него не является оценкой факториала.
