# Потоки в сетях и теорема Форда—Фалкерсона

Поток переносит величину от источника к стоку с ограничениями на дугах. Минимальный разрез даёт предел возможной передачи, и этот предел достижим.

## Сеть, дивергенция и поток

Сеть — конечный ориентированный граф с выделенными источником $s$ и стоком $t$, $s\ne t$, и неотрицательными конечными пропускными способностями $c(e)$. В исходной упрощённой модели у источника нет входящих, у стока нет исходящих дуг; основные определения работают и при их наличии.

Для функции на дугах

$$\operatorname{div}(f,u)=\sum_{u\to v}f(u,v)-\sum_{v\to u}f(v,u).$$

Поток удовлетворяет $0\le f(e)\le c(e)$ для каждой дуги и $\operatorname{div}(f,u)=0$ при $u\notin\{s,t\}$. Величина потока $|f|=\operatorname{div}(f,s)$. Число $f(e)$ — поток на отдельной дуге; его не следует смешивать с общей величиной $|f|$.

## Разрез и равенство потока через него

Пусть $V=S\sqcup T$, $s\in S$, $t\in T$. Обозначим $P^+$ дуги из $S$ в $T$, $P^-$ — из $T$ в $S$. Тогда

$$F(P^+)=\sum_{e\in P^+}f(e),\quad F(P^-)=\sum_{e\in P^-}f(e),\quad c(S,T)=\sum_{e\in P^+}c(e).$$

**Уточнение источника:** в определении «пропускная способность разреза» сначала суммируются дуги обоих направлений; для теоремы о максимальном потоке нужна сумма только из $S$ в $T$. Сумма обоих направлений относится к другой величине и не заменяет $c(S,T)$.

**Лемма и доказательство.**

$$|f|=F(P^+)-F(P^-).$$

Просуммируем $\operatorname{div}(f,u)$ по $u\in S$. Внутренняя дуга учитывается с плюсом у начала и минусом у конца, её вклад сокращается. Дуга $S\to T$ остаётся с плюсом, $T\to S$ — с минусом. С другой стороны, все дивергенции внутри $S$, кроме источника, равны 0, поэтому сумма равна $|f|$.

Сумма дивергенций по всему $V$ равна 0 тем же попарным сокращением, откуда

$$\operatorname{div}(f,s)=-\operatorname{div}(f,t).$$

## Верхняя оценка разрезом

$$|f|=F(P^+)-F(P^-)\le F(P^+)\le c(S,T).$$

Первая оценка использует неотрицательность обратного потока, вторая — ограничения на дугах. Следовательно,

$$\max_f|f|\le\min_{(S,T)}c(S,T).$$

В источнике промежуточная оценка через $F(P)$ записана для обоих направлений; она верна как более слабая, но не даёт нужного точного определения минимального разреза без уточнения выше.

## Остаточная сеть и увеличивающий путь

У каждой исходной дуги $u\to v$ есть остаточная прямая дуга ёмкости $c(u,v)-f(u,v)$, если эта величина положительна, и обратная $v\to u$ ёмкости $f(u,v)$, если поток положителен. Обратная дуга означает возможность отменить часть ранее назначенного потока; это не добавленная физическая пропускная способность.

Если исходно присутствуют дуги обоих направлений, остаточные вклады удобно хранить раздельно по исходным дугам либо суммировать с аккуратным восстановлением потока. Нельзя молча отождествлять физическую обратную дугу и отмену потока.

Путь из $s$ в $t$ по положительным остаточным ёмкостям — увеличивающий. Возьмём $\varepsilon>0$, равное минимуму ёмкостей на нём. По прямому проходу увеличим исходный поток на $\varepsilon$, по обратному уменьшим. Ограничения $[0,c(e)]$ сохраняются, в промежуточных вершинах изменения входа и выхода компенсируются, а величина потока возрастает на $\varepsilon$.

## Теорема о максимальном потоке и минимальном разрезе

$$\boxed{\max_f|f|=\min_{(S,T)}c(S,T).}$$

Эквивалентны: поток максимален; увеличивающего пути нет; существует разрез, чья пропускная способность равна величине потока.

**Существование максимума — дополнительный промежуточный шаг.** Допустимые потоки образуют непустое (есть нулевой поток), замкнутое ограниченное множество в конечномерном пространстве дуг. Непрерывная линейная функция $|f|$ достигает максимума. Это оправдывает начальное «возьмём максимальный поток» в доказательстве PDF при вещественных ёмкостях.

Возьмём максимальный $f$. Увеличивающего пути нет, иначе описанное изменение противоречит максимальности. Пусть $S$ — вершины, достижимые из $s$ по остаточной сети, $T=V\setminus S$. $s\in S$, $t\in T$; обе части непусты.

Для исходной дуги $u\in S\to v\in T$ остаток $c(e)-f(e)$ должен быть 0, иначе $v$ достижима. Поэтому $f(e)=c(e)$. Для исходной дуги $v\in T\to u\in S$ поток должен быть 0, иначе существует остаточная дуга $u\to v$. Значит

$$|f|=F(P^+)-F(P^-)=\sum_{P^+}c(e)-0=c(S,T).$$

Все потоки ограничены сверху любым разрезом; найденные поток и разрез имеют одинаковые значения, следовательно, оба оптимальны. То же рассуждение доказывает, что любой поток без увеличивающего пути максимален; равенство с ёмкостью некоторого разреза также сразу доказывает максимальность. Это объединяет версии доказательства PDF и двух рукописных фрагментов.

## Алгоритм Форда—Фалкерсона

Начинаем с нулевого потока. Строим остаточную сеть, ищем увеличивающий путь, находим его минимальную остаточную ёмкость и увеличиваем поток. Когда пути нет, множество остаточно достижимых вершин даёт минимальный разрез; это проверяемое свидетельство результата.

При целочисленных ёмкостях все потоки остаются целыми, каждое увеличение хотя бы 1; величина ограничена суммарной ёмкостью исходящих из $s$ дуг, поэтому процесс заканчивается. Для рациональных ёмкостей можно привести их к общему знаменателю и получить тот же вывод. **Дополнительное ограничение алгоритмического утверждения:** для произвольных вещественных ёмкостей доказательство существования максимума само по себе не доказывает завершение любого произвольного выбора путей; это разные утверждения.
