# Линейные рекуррентные соотношения

Рекуррентное соотношение определяет следующие элементы последовательности через предыдущие. Линейность позволяет складывать решения, а характеристический многочлен подсказывает экспоненциальные решения.

## Последовательности и начальные данные

Последовательность может быть бесконечной, например $x_n=(2n+1)/(n+2)$, или конечной, как $\binom n0,\ldots,\binom nn$ при фиксированном $n$. Равенство Паскаля

$$\binom nk=\binom{n-1}k+\binom{n-1}{k-1}$$

— пример рекуррентной связи между уровнями треугольника коэффициентов.

Линейное однородное соотношение порядка $k$ с постоянными коэффициентами:

$$x_{n+k}+p_{k-1}x_{n+k-1}+\cdots+p_1x_{n+1}+p_0x_n=0.$$

Коэффициент при следующем элементе равен 1, поэтому по $x_n,\ldots,x_{n+k-1}$ однозначно находится $x_{n+k}$. Последовательное применение показывает, что первые $k$ значений однозначно определяют решение. «Однородное» означает нулевую правую часть, а «линейное» — отсутствие произведений элементов между собой и нелинейных функций от них.

## Линейная комбинация решений

Если $a_n,b_n$ — решения, то $C_1a_n+C_2b_n$ — решение для любых постоянных $C_1,C_2$.

**Доказательство из лекции.** Подставим комбинацию в левую часть:

$$C_1a_{n+k}+C_2b_{n+k}+\sum_{j=1}^kp_{k-j}(C_1a_{n+k-j}+C_2b_{n+k-j})$$
$$=C_1\left(a_{n+k}+\sum_{j=1}^kp_{k-j}a_{n+k-j}\right)+C_2\left(b_{n+k}+\sum_{j=1}^kp_{k-j}b_{n+k-j}\right)=0.$$

Частное решение — конкретная последовательность, удовлетворяющая соотношению при всех допустимых $n$. Общее решение — всё семейство решений; одна найденная экспонента не обязана его исчерпывать.

## Характеристический многочлен

$$P(\lambda)=\lambda^k+p_{k-1}\lambda^{k-1}+\cdots+p_1\lambda+p_0.$$

Если $P(\lambda)=0$, то $x_n=\lambda^n$ удовлетворяет соотношению:

$$\lambda^{n+k}+\sum_{j=1}^kp_{k-j}\lambda^{n+k-j}=\lambda^nP(\lambda)=0.$$

При нулевом корне и $n=0$ начальное значение следует задать согласованно ($0^0$ не подменять вычислением вне выбранного соглашения). В приведённом в лекции примере корни ненулевые.

## Числа Фибоначчи в соглашении лекции

В источнике $f_0=f_1=1$, $f_{n+2}=f_{n+1}+f_n$. Это сдвиг привычного соглашения $F_0=0,F_1=1$: здесь $f_n=F_{n+1}$.

Характеристический многочлен $\lambda^2-\lambda-1$ имеет корни

$$\varphi=\frac{1+\sqrt5}{2},\qquad\psi=\frac{1-\sqrt5}{2}.$$

Линейные комбинации $A\psi^n+B\varphi^n$ являются решениями. Начальные данные дают $A+B=1$, $A\psi+B\varphi=1$. Отсюда $A=-\psi/\sqrt5$, $B=\varphi/\sqrt5$, поэтому

$$\boxed{f_n=\frac{\varphi^{n+1}-\psi^{n+1}}{\sqrt5}.}$$

**Дополнительное завершение записи источника:** в PDF система для коэффициентов выписана, но коэффициенты не найдены. Полученное решение имеет правильные первые два значения и удовлетворяет рекурсии; по единственности решения с двумя начальными значениями оно совпадает со всей последовательностью. Тем самым не требуется без доказательства утверждать полноту произвольного семейства экспонент.

## Мастер-теорема для оценки рекурсивных алгоритмов

В лекции сформулирована без доказательства версия верхних оценок: для

$$T(n)=aT(n/b)+O(n^c),\qquad T(1)=O(1),\quad a\in\mathbb N,\ a\ge1,\ b>1$$

получаем

$$T(n)=\begin{cases}
O(n^c),&c>\log_ba,\\
O(n^c\log n),&c=\log_ba,\\
O(n^{\log_ba}),&c<\log_ba.
\end{cases}$$

**Дополнительное объяснение механизма для $n=b^h$.** На уровне $i$ имеется $a^i$ задач размера $n/b^i$, суммарная работа $O(n^c(a/b^c)^i)$. Всего $h=\log_bn$ уровней и $a^h=n^{\log_ba}$ листьев. Если $a/b^c<1$, геометрическая сумма ограничена; если равно 1, каждый уровень вносит $O(n^c)$ и уровней $O(\log n)$; если больше 1, доминируют последние уровни и листья. Это объясняет все три случая. Для целочисленного алгоритма нужны соглашения об округлении размера и ограниченные базовые случаи; они в короткой формуле PDF не указаны. Из одной лишь добавки $O(n^c)$ нельзя автоматически заменить ответы на $\Theta$ без нижней оценки работы.
