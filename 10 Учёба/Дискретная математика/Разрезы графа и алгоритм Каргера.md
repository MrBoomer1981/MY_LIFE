# Разрезы графа и алгоритм Каргера

Разрез отделяет одну непустую часть вершин от другой. Случайное стягивание ищет минимальный разрез, постепенно объединяя вершины и сохраняя кратности рёбер.

## Определение разреза

Для неориентированного графа и $\varnothing\ne A\subsetneq V$ обозначим

$$\delta(A)=\{uv\in E\mid u\in A,\ v\in V\setminus A\}.$$

Вес разреза $c(A)=\sum_{e\in\delta(A)}w(e)$, для невзвешенного графа — число рёбер с учётом кратностей. Минимальный разрез минимизирует этот вес. Для связного графа его удаление нарушает связность. В потоковой сети дополнительно фиксируют $s\in A,t\notin A$ и учитывают направления, см. [[Потоки в сетях и теорема Форда—Фалкерсона]].

В рукописи [[IMG_3914.HEIC]] фраза «максимальный разрез — минимальный разрез» неверна: максимальный разрез максимизирует вес пересекающих рёбер и является другой задачей. Алгоритм Каргера ниже ищет минимум без фиксированных $s,t$.

## Стягивание

При стягивании ребра $uv$ две вершины заменяются одной супервершиной $u\cup v$, содержащей все исходные метки. Все остальные инцидентные рёбра переходят к ней. Петли удаляются; кратные рёбра **сохраняются**, иначе меняется вес разрезов и распределение случайного выбора.

Взвешенная запись операции: для любой другой супервершины $x$ новый вес между $x$ и $u\cup v$ равен $w(x,u)+w(x,v)$, отсутствующему ребру соответствует 0. Рёбра между прочими вершинами не меняются. Именно это выражает четырёхслучайная формула $c'(e)$ в «8.pdf».

## Алгоритм

Для связного мультиграфа на $n\ge2$ вершинах:

1. Пока вершин больше двух, равновероятно выбираем одно из текущих рёбер с учётом кратности и стягиваем его.
2. Две оставшиеся супервершины задают разбиение исходного $V$. Все оставшиеся рёбра — его разрез.
3. Повторяем запуск независимо из исходного графа и сохраняем самый лёгкий найденный разрез.

Веса можно обрабатывать как кратности для целочисленных весов; для положительных вещественных весов выбирают ребро **пропорционально его весу**, складывая веса после стягивания. Равновероятный выбор рёбер с разными весами не даёт доказанной ниже оценки.

## Четыре леммы из источника

**1. Связность супервершины.** Исходные вершины, слившиеся в одну супервершину, соединены путями из стянутых рёбер. Сначала супервершины одноэлементны. Стягивание ребра соединяет два уже связных набора, поэтому их объединение связано. Индукция даёт утверждение для всех шагов.

**2. Минимальный разрез не уменьшается при стягивании.** Любое разбиение супервершин поднимается до разбиения исходных вершин с тем же весом пересекающих рёбер: все вершины каждой супервершины оказываются с одной стороны. Значит у стянутого графа возможных разрезов меньше и минимум не меньше исходного. Если ребро выбранного исходного минимального разреза не стянуто, а его концы никогда не слились, этот разрез сохраняется с прежним весом, поэтому минимум равен прежнему.

**3. Оценка числа рёбер.** Если минимальный разрез имеет $c$ рёбер, степень каждой из $r$ текущих вершин не меньше $c$, поскольку разрез, изолирующий одну вершину, допустим. Поэтому $2m=\sum d(v)\ge rc$ и $m\ge rc/2$. Для взвешенного случая заменяем степени и $m$ их суммарными весами.

**4. Условие сохранения фиксированного разреза.** Конечные супервершины совпадают со сторонами $A,B$ тогда и только тогда, когда ни одно ребро $\delta(A)$ не стянуто. Необходимость: стягивание такого ребра навсегда смешало бы стороны. Достаточность: если исходные $a\in A,b\in B$ оказались в одной супервершине, по лемме 1 между ними есть путь из стянутых рёбер; он должен пересечь разрез, противоречие. В конце супервершин две, значит они и есть обе стороны.

## Вероятность одного запуска

Фиксируем один минимальный разрез веса $c$. При условии, что он сохранился до шага с $r$ супервершинами, его вес всё ещё $c$, а суммарный вес рёбер не меньше $rc/2$. Вероятность случайно стянуть его ребро не больше

$$\frac{c}{rc/2}=\frac2r.$$

Следовательно, вероятность выживания всех $n-2$ стягиваний не меньше

$$\prod_{r=n}^{3}\left(1-\frac2r\right)=\frac{n-2}{n}\frac{n-3}{n-1}\cdots\frac13=\frac2{n(n-1)}\ge\frac2{n^2}.$$

**Уточнение источника:** отдельная условная вероятность в «8.pdf» записана как равенство $2/r$, но из оценки числа рёбер следует неравенство $\le2/r$. Произведение даёт нижнюю оценку успеха, а не точную вероятность. Другие минимальные разрезы могут увеличить шанс найти какой-либо минимум.

## Усиление повторениями

После $N$ независимых запусков вероятность ни разу не найти фиксированный минимум не больше

$$\left(1-\frac2{n^2}\right)^N\le e^{-2N/n^2}.$$

Использовано $1-x\le e^{-x}$; знак «минус» нельзя потерять. При $N=\lceil n^2\ln n\rceil$ ошибка не больше $e^{-2\ln n}=n^{-2}$. Каждый запуск выдаёт настоящий разрез; ошибка означает, что его вес больше минимального. Хранить нужно минимальный вес среди запусков, а не последний результат.
