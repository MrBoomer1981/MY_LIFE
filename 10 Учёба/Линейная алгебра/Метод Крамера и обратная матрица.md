# Метод Крамера и обратная матрица

[[10 Учёба/Линейная алгебра/Линейная алгебра|Линейная алгебра]]

Для квадратной матрицы с ненулевым определителем существует обратная, а СЛАУ имеет единственное решение. Присоединённая матрица даёт формулу обратной; разложения по дополнениям объясняют формулы Крамера.

## Присоединённая матрица

Пусть $C_{ij}=(-1)^{i+j}M_{ij}$ — алгебраические дополнения элементов $A$. Матрица дополнений $C=(C_{ij})$. **Союзная**, или **присоединённая**, матрица:
$$\operatorname{adj}A=C^T,\qquad(\operatorname{adj}A)_{ij}=C_{ji}.$$
В источнике матрица дополнений обозначена $A^*$, а союзная — $\widehat A$. Это обычное транспонирование, не комплексное сопряжение.

**Тождество:**
$$A\operatorname{adj}A=\operatorname{adj}A\,A=(\det A)E.$$
Доказательство:
$$(A\operatorname{adj}A)_{ik}=\sum_ja_{ij}C_{kj}.$$
При $k=i$ это разложение $\det A$ по строке $i$; при $k\ne i$ — сумма с чужими дополнениями, равная нулю. Для произведения в другом порядке применяют разложение по столбцам.

## Формула обратной и критерий обратимости

Если $\det A\ne0$, деление тождества на определитель даёт
$$A^{-1}=\frac{1}{\det A}\operatorname{adj}A
=\frac1{\det A}\begin{pmatrix}
C_{11}&C_{21}&\cdots&C_{n1}\\
\vdots&\vdots&\ddots&\vdots\\
C_{1n}&C_{2n}&\cdots&C_{nn}
\end{pmatrix}.$$
Обратно, если $A$ обратима, то $1=\det E=\det A\det A^{-1}$, значит $\det A\ne0$. Таким образом,
$$A\text{ обратима}\iff\det A\ne0,\qquad\det A^{-1}=\frac1{\det A}.$$
Для $2\times2$:
$$\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}
=\frac1{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix},\qquad ad-bc\ne0.$$

## Теорема Крамера и доказательство

Пусть $AX=B$ — система $n$ уравнений с $n$ неизвестными, $\Delta=\det A\ne0$. Тогда
$$x_j=\frac{\Delta_j}{\Delta},\qquad j=1,\ldots,n,$$
где $\Delta_j$ — определитель матрицы, полученной заменой столбца $j$ на $B$. Разложение по этому столбцу:
$$\Delta_j=\sum_{i=1}^nb_iC_{ij}.$$

Умножим уравнение $i$ на $C_{ij}$ и сложим по $i$. Коэффициент при $x_j$ равен $\sum_i a_{ij}C_{ij}=\Delta$, а при $x_k$, $k\ne j$, равен $\sum_i a_{ik}C_{ij}=0$. Справа получаем $\Delta_j$. Следовательно, любое решение удовлетворяет $\Delta x_j=\Delta_j$ и может быть только одним.

Существование обеспечено формулой $X=A^{-1}B$: умножение на $A$ даёт $B$. Её координаты равны
$$x_j=\frac1\Delta\sum_iC_{ij}b_i=\frac{\Delta_j}{\Delta}.$$
Это одновременно матричный метод решения. При $\Delta=0$ данные формулы деления неприменимы: систему рассматривают методом Гаусса.

## Примеры

Для системы
$$x+y+z=6,\qquad2x-y+z=3,\qquad x+2y-z=2$$
получаем $\Delta=7$, $\Delta_1=7$, $\Delta_2=14$, $\Delta_3=21$, поэтому $(x,y,z)=(1,2,3)$ — как в [[СЛАУ, метод Гаусса и пространство решений|методе Гаусса]].

Для
$$2x+y=5,\qquad x+3y=10$$
имеем
$$\Delta=2\cdot3-1\cdot1=5,$$
$$\Delta_x=\begin{vmatrix}5&1\\10&3\end{vmatrix}=5,\qquad
\Delta_y=\begin{vmatrix}2&5\\1&10\end{vmatrix}=15.$$
Значит, $x=1$, $y=3$. Для матрицы этой системы:
$$A^{-1}=\frac15\begin{pmatrix}3&-1\\-1&2\end{pmatrix}.$$
Проверка:
$$AA^{-1}=\frac15\begin{pmatrix}6-1&-2+2\\3-3&-1+6\end{pmatrix}=E.$$
