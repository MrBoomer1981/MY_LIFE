# Группы и подгруппы

[[10 Учёба/Линейная алгебра/Линейная алгебра|Линейная алгебра]]

Группа описывает действия, которые можно выполнять последовательно и отменять. Подгруппа — часть группы, замкнутая относительно этих действий и их обратных.

## Определение и основные следствия

**Группа** — множество $G$ с внутренней операцией, удовлетворяющей трём условиям:

1. $(ab)c=a(bc)$ — ассоциативность.
2. Есть $e$ с $ea=ae=a$ для всех $a$.
3. Для любого $a$ есть $a^{-1}$ с $aa^{-1}=a^{-1}a=e$.

Группа **абелева**, если дополнительно $ab=ba$. Мультипликативной записи $(\cdot,e,a^{-1})$ соответствует аддитивная $(+,0,-a)$.

Обратный элемент единственен. Если $g'$ — левый обратный, а $g''$ — правый, то
$$g'=g'e=g'(gg'')=(g'g)g''=eg''=g''.$$

Обратный к произведению берётся в обратном порядке:
$$(ab)^{-1}=b^{-1}a^{-1},$$
поскольку $(ab)(b^{-1}a^{-1})=a(bb^{-1})a^{-1}=e$ и аналогично с другой стороны. В группе можно сокращать: из $ab=ac$ умножением слева на $a^{-1}$ получаем $b=c$; действует и правое сокращение.

## Примеры

Группы по сложению: $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$, а также $\mathbb Z/m\mathbb Z$. По умножению группами являются ненулевые элементы полей: $\mathbb Q^*,\mathbb R^*,\mathbb C^*$.

$S_n$ — группа перестановок $n$ элементов, операция — композиция, число элементов $n!$. $GL_n(K)$ — группа обратимых матриц. Группа $U(1)=\{z\in\mathbb C:|z|=1\}$ состоит из комплексных чисел единичного модуля, а $\mu_n=\{z:z^n=1\}$ — из корней $n$-й степени из единицы.

$(\mathbb N,+)$ не группа из-за отсутствия противоположных. $(\mathbb Z,\cdot)$ не группа: обратимы только $1$ и $-1$.

### Симметрии, углы и булева группа

В лекции «Структура группы» приведены $D_3$ — симметрии правильного треугольника, $S_n$ — перестановки и группа вращений граней кубика Рубика. Операция во всех случаях — последовательное выполнение преобразований; единица ничего не меняет, обратное действие отменяет исходное.

Группа углов записывается $\mathbb R/(2\pi\mathbb Z)$. Для представителей $x,y\in[0,2\pi)$
$$x\oplus y=\begin{cases}x+y,&x+y<2\pi,\\x+y-2\pi,&x+y\ge2\pi.\end{cases}$$
Ограничение представителей нужно для этой формулы с одним вычитанием; для произвольных вещественных берётся класс суммы по модулю $2\pi$.

В булевой группе $\mathcal P(X)$ операция — $\triangle$, единица — $\varnothing$, обратный к $A$ — само $A$. **Дополнительное пояснение:** по принадлежности отдельного элемента симметрическая разность соответствует сложению $0$ и $1$ по модулю $2$, откуда ассоциативность и коммутативность.

Группа физических размерностей: произведение величин складывает показатели основных единиц, например $L^aM^bT^c$. Единица — безразмерная величина, обратная размерность $L^{-a}M^{-b}T^{-c}$. Речь о формальных размерностях, а не о значениях физических величин.

## Критерий подгруппы

**Критерий подгруппы — это короткая проверка: является ли выбранная часть группы сама группой.**

Подмножество $H\subseteq G$ — **подгруппа**, $H\le G$, если с унаследованной операцией оно само является группой. Для **непустого** $H$ достаточно и необходимо:
$$a,b\in H\ \Longrightarrow\ ab\in H,\quad a^{-1}\in H.$$
Ассоциативность наследуется. Из непустоты берём $a\in H$; тогда $aa^{-1}=e\in H$, а обратные и произведения остаются в $H$.

Эквивалентен один критерий:
$$H\ne\varnothing,\qquad a,b\in H\ \Longrightarrow\ ab^{-1}\in H.$$
Действительно, при $a=b$ получаем $e\in H$, затем $eb^{-1}=b^{-1}\in H$, а после этого $a(b^{-1})^{-1}=ab\in H$. Обратное следует из замкнутости подгруппы.

В соглашении преподавателя $\{e\}$ — тривиальная подгруппа, $G$ — несобственная; остальные подгруппы — собственные. **Простой** называют нетривиальную группу без нетривиальных собственных нормальных подгрупп; нормальность разобрана в [[Фактор-группы и теорема об изоморфизме]].

Примеры:

- $n\mathbb Z\le(\mathbb Z,+)$;
- $\mathbb R_{>0}\le(\mathbb R^*,\cdot)$;
- $SL_n(K)=\{A:\det A=1\}\le GL_n(K)$;
- $A_n$, чётные перестановки, — подгруппа $S_n$;
- $\mu_n\le U(1)\le\mathbb C^*$.

Повороты квадрата на $0^\circ,90^\circ,180^\circ,270^\circ$ образуют группу. Обратный к $90^\circ$ — поворот на $270^\circ$. Повороты $0^\circ,180^\circ$ образуют подгруппу: два поворота на $180^\circ$ дают тождественный. Набор $\{0^\circ,90^\circ\}$ не замкнут, поскольку $90^\circ+90^\circ=180^\circ$.

**Различие терминологии:** в других источниках «собственная подгруппа» может означать любую $H\ne G$, включая $\{e\}$. Здесь используется соглашение преподавателя.
