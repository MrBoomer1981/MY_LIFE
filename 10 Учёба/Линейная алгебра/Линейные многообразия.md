# Линейные многообразия

[[10 Учёба/Линейная алгебра/Линейная алгебра|Линейная алгебра]]

Линейное многообразие — сдвиг подпространства. В нём выбирается точка, относительно которой остальные точки описываются векторами из несущего подпространства.

## Определение и несущая часть

Пусть $L\le X(k)$, $x_0\in X$ фиксирован. Определим
$$M=x_0+L=\{x_0+x:x\in L\}.$$
$L$ называется **несущим подпространством**; $x_0$ — выбранный представитель многообразия. При $x_0\notin L$ многообразие не является подпространством: $0\in x_0+L$ означало бы $-x_0\in L$ и $x_0\in L$. Если $x_0\in L$, то $x_0+L=L$, поскольку оба включения следуют из замкнутости $L$ по сложению и вычитанию. Значит, $M$ — подпространство тогда и только тогда, когда $x_0\in L$.

## Когда два сдвига совпадают

**Теорема 4.2:** эквивалентны
$$x_0+L=y_0+L\quad\Longleftrightarrow\quad y_0\in x_0+L\quad\Longleftrightarrow\quad y_0-x_0\in L.$$

**$(1)\Rightarrow(2)$.** $y_0=y_0+0\in y_0+L=x_0+L$. В записи преподавателя можно взять общую точку $x_0+z=y_0+z'$; тогда $y_0=x_0+(z-z')\in x_0+L$.

**$(2)\Rightarrow(3)$.** Если $y_0=x_0+z$, $z\in L$, то $y_0-x_0=z\in L$.

**$(3)\Rightarrow(1)$.** Положим $z=y_0-x_0\in L$. Для $x=x_0+z'\in x_0+L$ получаем $x=y_0+(z'-z)\in y_0+L$, поскольку $z'-z\in L$. Обратно, если $y=y_0+w\in y_0+L$, то $y=x_0+(z+w)\in x_0+L$. Оба включения доказаны, значит, множества равны.

Поэтому многообразие можно представить через любую его точку: при $y_0\in M$ имеем $M=y_0+L$.

## Единственность несущего подпространства

**Лемма 4.7:** если $x_0+L=y_0+L'$, то $L=L'$.

**Доказательство по преподавателю с промежуточным переходом.** Так как $x_0$ лежит в общем многообразии, $x_0\in y_0+L'$. По предыдущей теореме для $L'$ получаем $y_0+L'=x_0+L'$. Теперь $x_0+L=x_0+L'$. Для каждого $u\in L$ точка $x_0+u$ лежит справа, поэтому есть $v\in L'$ с $x_0+u=x_0+v$, откуда $u=v\in L'$. Значит, $L\subseteq L'$. Для каждого $v\in L'$ тем же равенством множеств найдём $u\in L$ и получим $v=u\in L$. Значит, $L'\subseteq L$, и подпространства равны.

**Дополнительное пояснение:** $L=\{a-b:a,b\in M\}$. Любая разность $a-b$ лежит в $L$; обратно, $u\in L$ равен $(x_0+u)-x_0$. Это ещё один способ увидеть, почему несущая часть определяется самим $M$, хотя представитель не единственен.

## Размерность и геометрические названия

Определение $\dim_k M:=\dim_k L$ корректно благодаря единственности $L$. При $\dim L=1$ это прямая, при $\dim L=2$ — плоскость, при $\dim L=d$ — $d$-мерная плоскость. В конечномерном $X$ гиперплоскость имеет $\dim L=\dim X-1$.

**Дополнительный разобранный пример:** в $\mathbb R^2$ множество $M=\{(s,1):s\in\mathbb R\}$ равно $(0,1)+\langle(1,0)\rangle$. Та же прямая равна $(3,1)+\langle(1,0)\rangle$, поскольку разность представителей $(3,0)$ лежит в несущей прямой. Размерность $M$ равна $1$, нуля в $M$ нет.
