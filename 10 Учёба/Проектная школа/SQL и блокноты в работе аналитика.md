# SQL и блокноты в работе аналитика

> [!abstract] Суть
> SQL помогает отбирать, соединять и агрегировать данные в базе. Python и интерактивные блокноты удобны для последовательного исследования, визуализации и автоматизации.

## Разделение задач

| Инструмент | Задачи в презентации |
|---|---|
| SQL | Получить данные из базы, отфильтровать строки, объединить таблицы и рассчитать метрики |
| Python | EDA, очистка файлов, графики, статистика, машинное обучение и автоматизация |
| SQL-клиент | Подключиться к системе, увидеть таблицы, выполнить запрос и получить результат |
| Блокнот | Сочетать код, пояснения, таблицы и графики в одном документе |

SQL и Python могут использоваться в одном процессе: необходимые данные получают запросом, затем исследуют и визуализируют. Это распределение работы из вводного занятия; оно не запрещает иные конвейеры.

## Запрос описывает нужные данные

SQL в презентации определяется как язык запросов к базам данных: аналитик описывает, какой результат нужен.

Основные элементы:

- SELECT — выбираемые поля и выражения;
- FROM — исходная таблица или источник;
- WHERE — условие отбора строк;
- JOIN — объединение таблиц по условию;
- GROUP BY — группировка для расчёта итогов.

**Дополнительное пояснение:** JOIN нужно сопоставлять с [[Модель данных сервиса временной занятости#Почему соединение может изменить итог|кратностью связей]], а GROUP BY — с единицей итогового результата. Правильный синтаксис не гарантирует предметно правильного показателя.

## Пример из лекции

~~~sql
SELECT
    *
FROM shifts
LIMIT 10;
~~~

Звёздочка выбирает все поля. Источник — таблица shifts. LIMIT ограничивает результат максимум десятью строками; если строк меньше, вернётся меньше.

**Уточнение подписи «первые 10 строк»:** без ORDER BY порядок не задан. Запрос удобен для просмотра части таблицы, но не означает «десять самых ранних смен» или воспроизводимый случайный отбор. Это поведение явно описано в [документации PostgreSQL о LIMIT](https://www.postgresql.org/docs/current/queries-limit.html).

Полное имя таблицы, схема, поля и подключение к учебной базе в PDF не предоставлены. shifts — имя из примера, оно не объявляется уже доступной таблицей на компьютере пользователя.

## Роль DBeaver и подключение

DBeaver в занятии представлен как SQL-редактор и клиент баз данных. Он показывает таблицы, отправляет запросы и выводит результат. В качестве других клиентов названы DataGrip, pgAdmin для PostgreSQL и веб-редакторы вроде Redash.

Порядок подключения, описанный на слайде:

1. Владелец базы предоставляет доступ и параметры соединения.
2. В клиенте выбираются СУБД и драйвер.
3. Указываются адрес host, порт, база, логин и пароль; при необходимости настраиваются VPN и SSL.
4. После проверки соединения запрос выполняется в SQL-редакторе.

Это описание инструмента и процесса из учебного материала. Конкретные реквизиты в источнике отсутствуют. Драйвер и возможности SQL зависят от выбранной системы.

## Jupyter Notebook и Colab

Jupyter Notebook описан как интерактивный блокнот с кодом, таблицами и графиками. В презентации приведён локальный вариант, например установка через Anaconda.

Colab — облачный сервис для работы с Jupyter-блокнотами через браузер; локальная установка Python для такого способа не требуется. Это подтверждает [официальное описание Colab](https://research.google.com/colaboratory/faq.html). В слайдах написано Google Collab; название сервиса — Google Colab, сокращение от Colaboratory.

Адреса из источника: [Anaconda](https://www.anaconda.com/download) и [Colab](https://colab.google/). Они сохраняют происхождение упомянутых сред; выбор конкретной установки в этом конспекте не выполняется.

**Дополнительное пояснение:** блокнот сохраняет код и результаты ячеек, но порядок их выполнения влияет на состояние переменных. Показанная таблица должна соотноситься с тем кодом и теми исходными данными, которыми она была получена. Сохранённый вывод не заменяет воспроизводимость.

В этой презентации нет Python-кода загрузки CSV и готового исследовательского блокнота. Упоминание EDA обозначает назначение инструмента; полноценный разбор методов разведочного анализа появится с соответствующим материалом курса.
